# @morpha/web-runtime

Morphaシステムで作成されたアニメーションを、Webブラウザ（WebGL）上でレンダリングおよび再生するためのTypeScriptランタイムライブラリです。

## 主な機能
- WebGLを用いたメッシュ変形・深度マップ(Depth Map)の描画
- `.morphamotion` データに基づくアニメーション再生
- Morpha Studio エディタ上のプレビュー機能バックエンド

## 開発環境

```bash
# TypeScriptのウォッチモードでビルド
npm run dev
```

## 依存
- `@morpha/core`
