# Morpha Studio (@morpha/editor)

MorphaアニメーションシステムのためのWebベースのGUIエディタです。
Vue 3 および Nuxt 3 を使用して構築されています。

## 特徴
- キャンバス上でのキャラクターメッシュ・ボーンの直感的な編集
- タイムラインおよびグラフエディタによるモーション作成
- 各種パラメータ（表情、頭の向きなど）の調整インスペクタ

## 開発環境

```bash
# 開発サーバーの起動 (localhost:3000)
npm run dev
```

### ビルド

```bash
npm run build
```
